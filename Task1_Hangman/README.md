# Task 1 — Professional Hangman Game

A polished console-based Hangman game built with Python.

## Features
- Random selection from five predefined words
- Maximum of six incorrect guesses
- Prevents duplicate guesses
- Validates user input
- Displays used letters and remaining attempts
- Replay support
- Session win statistics
- Functions with clear responsibilities

## Run

```bash
python hangman.py
```

## Concepts Used

Python functions, lists, strings, sets, `random`, loops, conditions, validation, and console I/O.
